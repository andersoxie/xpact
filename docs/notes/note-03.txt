v3 = v2 + one fix found by reading the diff:
- On fallback (resume attempt failed), should_defer_reparse_callbacks was called a second time.
  It keeps state between calls (it clears/sets deferred_reparse_*), so the second answer could
  differ and delay an error. Fix: l_deferral_decided -> the legacy path reuses the decision
  when l_input = input_buffer.

HOW TO RUN THINGS (copy/paste)
- CRC harness script fails under Windows PowerShell 5.1 (the exe prints "ok" to stderr and the
  script has ErrorActionPreference Stop). Run the compiled exe directly:
  build\baseline\chunked-crc\xpact_chunked_crc.exe --mode direct|buffer --chunk-sizes ... [--file X]
  My wrapper: scratchpad\crc.ps1 -Dir <dll dir> -Out <tsv>.
- Shim audit / CRC scripts always use build\native-eiffel\xpact.dll: copy the DLL+lib you want
  to test into that folder first. Put "C:\Program Files (x86)\Microsoft Visual Studio\Installer"
  on PATH (vswhere) or vcvars fails.
- Eiffel test matrix: .\scripts\run_eiffel_test_matrix.ps1 (no *> redirect!).
- No pwsh (PowerShell 7) on this PC.

DIFFERENTIAL TRACE TEST (scratchpad\trace) - strongest check of observable behaviour
- trace.c: for every file on stdin: XML_Parse in pieces of N; print every callback with
  XML_GetCurrentLineNumber/ColumnNumber/ByteIndex and its data; final status/error/position.
  Modes: events (start/end/text/PI/comment/CDATA/doctype/entitydecl), default (default handler
  only), suspend (XML_StopParser resumable every 3rd callback, then XML_ResumeParser).
- run.ps1 -Dir <dll dir> -Out <dir>: 7 runs over the W3C files < 2 KB (chunk 1) and < 8 KB
  (chunk 7, whole). Compare two output dirs with diff -r.
- v3 runs all 7 in ~3 s each; the baseline takes much longer (it is the old quadratic code).
