1. How to report an error
For each problem, record:
1. Problem: What went wrong?
2. Environment: Which machine, configuration, or build mode?
3. Command: The exact command you ran.
4. Expected result: What should have happened?
5. Actual result: What happened instead?
6. Error output: The exact error message or relevant log.
7. Investigation: What you checked and tried.
8. Cause: Confirmed cause, suspected cause, or still unknown.
9. Fix: What you changed, if anything.
10. Verification: Whether you reran the test and whether it passed.
Important: Don't report a suspected cause as a confirmed fact. Also, keep separate problems separate, even when they appear related.
2. How to report test results
For your XPact project, we also discussed recording a baseline of how the project behaves before making further fixes.

Your baselineLog was supposed to contain:
- Revision — Git commit or version tested.
- Configuration — assertions enabled, build mode, and environment.
- Commands and results — commands executed and their outcomes.
- Parser events — events generated by the parser for the XML inputs.
- Known failures — tests that fail and their observed behavior.
- Baseline limitations — what the tests do not yet prove.
