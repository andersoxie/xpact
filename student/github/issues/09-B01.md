## Goal
Accumulated failures in the main and native runtime test runners must make the process exit nonzero, independently of Eiffel `check` instructions.

## Why
Student guide, "P0 reliable test and benchmark outcomes". A run that reports failures but exits 0 shows up as green in CI.

## Done when
- [x] A deliberately failing test makes `xpact_tests.exe` exit nonzero ✅ ([#45](https://github.com/andersoxie/xpact/issues/45), PR [#62](https://github.com/andersoxie/xpact/pull/62))
- [x] Holds for workbench and finalized (with `-keep`) builds ✅ (12 runs, all as predicted)
- [x] `run_eiffel_test_matrix.ps1` reports the failure ✅
- [x] Before/after logs in `student/results/B01-nonzero-exit/` ✅ ([results](../../results/B01-nonzero-exit/README.md))

## Evidence / notes
Related findings: the missing `-keep` in the finalized lane, and the runner stopping at the first failure.
