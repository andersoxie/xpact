### Speed and safety

| ID | Problem | Seen in | Cause |
|---|---|---|---|
| **F05-1** | **Streaming is quadratic**: 2 MB in 64 KB chunks takes 55 s (Expat 0.6 s); **over 10 MB in total is rejected** even when streamed | security, CPython, Expat tests | ✅ **confirmed in the code:** each `XML_Parse` re-parses the whole buffer |
| **F07-1** | **Billion laughs through external entities is not stopped** (> 300 s; Expat stops after about 15 s) | libxml2 2 | 🟡 amplification counted per child parser |
| F06-1 | Assertions build: 3 of Expat's buffer and streaming tests take over 120 s | Expat tests 3 | 🟡 linked to F05-1 |
| F05-2 | Namespace URI containing the separator accepted (CVE-2022-25236) | security 1 | ❔ |
| F05-4 | Rejecting billion laughs takes 18 s (Expat 0.6 s) | security 2 | 🟡 |

### 🟡 By design, needs a decision with the supervisor

| Topic | Now | Expat |
|---|---|---|
| Hard limits (`src/xp_limits.e`) | depth 256, 1,024 attributes, names 512 KB, **10 MB input in total** | no limits |
| Allocator (`XML_ParserCreate_MM`) | not used by the Eiffel core: the 38 allocator tests of Expat cannot pass | used |
| 5th-edition names in the DLL | 4th-edition tables, like Expat (318 W3C cases "fail" on purpose) | 4th edition |

## ✅ What is solid

- [x] No crash and no hang in **2.03 million** random, mutated and generated inputs (tests 3, 4: 571,839 + 1,457,486)
- [x] No memory leak in 8 scenarios × 20,000 rounds (test 9)
- [x] Every broken UTF-8 sequence is rejected, also byte by byte (test 8)
- [x] No external file is read without a handler (XXE, test 5)
- [x] Internal billion laughs, recursion and 100,000-deep entity chains are handled (test 5)
- [x] The verdict never depends on how the input is chunked (test 2)
- [x] 361 of Expat's own C tests pass (test 6); CPython's `pyexpat` builds and mostly works on xpact (test 10)
- [x] The assertions build gives the same results as the normal build (tests 1, 2, 8, 10)

## 🛠 Shared tools ([harness/](harness/))

| File | What it does |
|---|---|
| [engines.py](harness/engines.py) | One document through `xpact.dll` (Expat C API via `ctypes`) or Expat; the same event list from both; `bare` mode without handlers |

| [w3c.py](harness/w3c.py) | The W3C catalog, loaded with the project's own runner |
